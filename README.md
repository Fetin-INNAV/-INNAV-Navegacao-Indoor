\# Sistema de Navegação Ponto a Ponto para Deficientes Visuais



\## 📌 Descrição do Projeto

Aplicativo de mobilidade interna focado em acessibilidade, projetado para guiar pessoas com deficiência visual em ambientes fechados onde o GPS convencional falha. O sistema utiliza zonas de proximidade via sensores Bluetooth (ESP32) para identificar a localização atual e fornecer rotas guiadas por comandos de voz (Text-to-Speech).



\## 🗂️ Estrutura do Repositório

\* `/app-mobile`: Código-fonte do aplicativo desenvolvido em Android Nativo com Kotlin.

\* `/hardware`: Firmware em C++ para configuração dos módulos ESP32 como Beacons BLE.

\* `/scripts-calibracao`: Scripts de análise matemática para filtragem do sinal RSSI.

\* `/docs`: Documentações, diagramas de grafos e especificações do projeto.
